# Task1: RLE Compression

## 📋 Описание

Реализация алгоритма сжатия строк **RLE (Run-Length Encoding)** с поддержкой валидации входных данных.

**Пример:**
- Вход: `aaabbcccdde`
- Выход: `a3b2c3d2e`

---

## 🏗️ Архитектура

```
Task1_StringCompression/
├── Compression/
│   ├── Interfaces/
│   │   └── ICompressor.cs          # Контракт для сжатия/распаковки
│   └── Services/
│       └── RleCompressor.cs        # Реализация RLE
└── Validation/
    ├── Interfaces/
    │   └── IValidator.cs           # Контракт для валидации (generic)
    └── Services/
        └── DefaultStringValidator.cs # Валидатор для строк (a-z)
```

### Ключевые принципы

- **Интерфейс `ICompressor`** — позволяет легко подменить алгоритм сжатия.
- **Интерфейс `IValidator<T>`** — гибкая валидация для любых типов данных.
- **Dependency Injection** — валидатор внедряется в компрессор через конструктор.
