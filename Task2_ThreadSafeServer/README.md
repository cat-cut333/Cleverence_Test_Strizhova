# Task2: ThreadSafeServer

## 📋 Описание

Потокобезопасный статический сервер с использованием `ReaderWriterLockSlim`.

**Сценарий:** множество читателей параллельно читают значение, писатели добавляют значения последовательно.

---

## 🏗️ Архитектура

```
Task2_ThreadSafeServer/
├── Server/
│   ├── Interfaces/
│   │   └── IStaticServer.cs        # Контракт сервера
│   └── Services/
│       └── StaticServer.cs         # Реализация с ReaderWriterLockSlim
└── Program.cs                       # Демонстрация работы
```

---

## 🧵 Многопоточность

| Особенность | Реализация |
|-------------|------------|
| **Читатели** | Могут работать параллельно (не блокируют друг друга) |
| **Писатели** | Выполняются последовательно (один за другим) |
| **Блокировка** | Читатели ждут окончания записи |
| **Защита** | Проверка на переполнение (`int.MaxValue`) |

## 📝 Ключевые особенности

- ✅ **Потокобезопасность** — корректная работа при параллельном доступе.
- ✅ **Оптимизация** — `ReaderWriterLockSlim` эффективнее `lock` при частом чтении.
- ✅ **Защита от переполнения** — проверка перед сложением.
